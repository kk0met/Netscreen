# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.1.0] - 2026-10-05
### Fixed
- Chromium-based browsers (Chrome, Edge, ...) no longer go black or freeze when the
  Minecraft window covers them.

### Added
- Client config `keepSourceRendering` (on by default), editable from the Mods screen.

## [1.0.0] - 2026-10-05
### Added
- In-HUD screen that mirrors any desktop window in real time (~30 FPS).
- Window picker with paging and refresh.
- Remembers the last chosen window and reattaches automatically.
- Three sizes (small / medium / large) and four screen corners (top-right by default).
- Optional media Play/Pause key binding.
- English and Italian translations.
